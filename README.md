# 📝 Language Detection

A simple yet effective project to detect the language of a given text using machine learning and natural language processing (NLP) techniques.  
This repository contains a Jupyter Notebook (`language_detection.ipynb`) that walks through data preprocessing, model training, and evaluation.

---

## 🚀 Features
- Detects the language of short and long text inputs
- Uses NLP preprocessing (cleaning, tokenization, etc.)
- Implements machine learning models for classification
- Visualizations for dataset insights and performance metrics
- Easy-to-follow Jupyter Notebook for reproducibility
